# Homebrew Tap

Homebrew tap for [wimpysworld](https://github.com/wimpysworld) tools.

## Usage

```bash
brew tap wimpysworld/tap
```

Then install any available formula:

```bash
brew install wimpysworld/tap/<formula>
```

## Formulae

Formulae are automatically published here via [GoReleaser](https://goreleaser.com/) on each upstream release.

| Formula | Repository |
|---------|------------|
| `ia-get` | [wimpysworld/ia-get](https://github.com/wimpysworld/ia-get) |
| `tailor` | [wimpysworld/tailor](https://github.com/wimpysworld/tailor) |

## Issues & Contributions
